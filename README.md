# Styling Dossier Mayank

Mobile-first personal styling & lookmaxxing web app companion (**Deep Autumn · Neutral-Warm Lean · 5'8" · 72 kg**).

## Features
- **Pair-On Studio:** Interactive solid-on-solid top + bottom + optional open layer + footwear visualizer with live harmony & 5'8" silhouette scoring, plus device-saved favorites.
- **Fit Matrix:** Compatibility breakdown for Regular/Boxy vs. Slim-Fit shirts paired with Korean pleated pants, relaxed-straight jeans, and bootcut jeans.
- **Color Palette & Skin Metrics:** Tap-to-copy hex swatches calibrated from 34 photos (CIELAB/ITA + real A/B draping proof).
- **Layering, Checks & Stripes Playbook:** Evidence-backed rules (including Thompson & Mikellidou 2011 Helmholtz illusion).
- **Beard, Hair & Proportions:** Grooming & posture cues tailored from real photo angles.
- **Occasion Capsules:** Smart Casual, Streetwear, Date Night & Festive Indian presets.
